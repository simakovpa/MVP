# Модуль «Испытания и измерения» — прототип

## Запуск

```bash
npm install
npm run dev
```

После запуска Vite покажет адрес в терминале. **Важно:** в проекте задан
`base: "/measures/"` (файл `vite.config.js`), поэтому открывать нужно именно

```
http://localhost:5173/measures/
```

а не просто `http://localhost:5173/` — иначе страница будет пустой.

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы появятся в `dist/`.

## Версии, под которые собран и протестирован прототип

- React 18.3
- Ant Design 5.21
- Vite 5.4

Эти версии проверены полной сборкой (`vite build`, 3001 модуль, без ошибок)
и реальным запуском dev-сервера с проверкой ответа по пути `/measures/`
перед передачей архива.

Если в вашем окружении уже стоят более новые версии (React 19 / AntD 6 /
Vite 8) — рекомендуется временно оставить именно эти зафиксированные версии
в `package.json`, пока прототип не будет проверен на совместимость с новым
мажорным Ant Design (в 6-й версии могли измениться некоторые пропы
компонентов).
